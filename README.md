# Yash Siwach — Forensic Science student portfolio

B.Sc. Forensic Science (2nd year), Geeta University, Panipat.

This is a **student training portfolio**. The 3D lab is an educational simulation, not a real casefile. Legal citations use BSA / BNSS / BNS (with former IEA / CrPC / IPC in brackets).

## Run locally

```bash
cd yash-forensic-portfolio
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build
npm run preview
```

## Fill your real details

Edit `src/data/profile.js` (empty strings stay hidden in the UI):

- LinkedIn URL
- Phone (optional)
- Exact internship organisation names and supervisors
- Whether you actually used SEM, AFIS, FTK Imager, Autopsy
- Resume PDF path after you add `public/resume.pdf`

Do not invent hashes, “verified” badges, or the title Forensic Scientist.

## Stack

React 18, Vite, Three.js / R3F, Framer Motion, Tailwind CSS.
